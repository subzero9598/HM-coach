HM Coach PWA

This package is ready to host as an installable Progressive Web App.

Files:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

How to install on iPhone:
1. Upload this folder to any HTTPS web host.
2. Open the website in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch HM Coach from the Home Screen.

How to install on Android:
1. Open the hosted site in Chrome.
2. Tap Install app / Add to Home Screen when offered.

Hosting options:
- GitHub Pages
- Netlify
- Cloudflare Pages
- Your own HTTPS domain

The app works offline after the first successful load.
Training data remains stored locally in the browser/app storage on that device.
Use Export JSON periodically for backup.
